Privacy policy

Last updated: 10 November 2026

Who uses this app

"Claude client access" is a private tool used only by Andrea Marec, for Google accounts that he controls. It is not offered to the public.

What data it accesses

With the account owner's consent, the app accesses Gmail, Google Calendar and Google Drive data of the signed-in account. It uses that data only to let the owner's AI assistant read, search, draft and organise the owner's own email, calendar and files on his request.

Where data is stored

Access tokens are stored only on the owner's own computer. The app has no server and no database. It does not sell, share or transfer Google user data to third parties, except to the AI model provider used to process the owner's own requests, and only as needed to answer them.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections. Deleting the local token files removes all stored access.

Contact

Use the support email shown on the Google sign-in (consent) screen of this app.
